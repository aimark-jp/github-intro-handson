# 02　変更を記録する

履歴と差分を読む（add / commit / push）

今日の本体です。**ここが通れば、残りは全部この形の繰り返し**になります。急がず進めてください。

**01 で作った自分のリポジトリで**やります。

---

## やること

自分のリポジトリの `README.md` を自己紹介に書き換えて、その変更を GitHub に記録します。

---

## 貼るプロンプト

```
README.md を、私の自己紹介に書き換えてください。中身は適当で構いません。

そのあと、変更を GitHub に上げてください。ただし次を守ってください。

・git status と git diff の結果は、省略せずそのまま全部見せる
・何が増えて何が減ったのかを説明する
・push まで終わったら止まる
```

---

## AI が返すはずのもの

打たれるのは、この5つです。**これが今日いちばん大事な1周**です。

```bash
git status          # 変わったファイルの一覧
git diff            # 中身がどう変わったか
git add README.md   # 「これを記録します」と選ぶ
git commit -m "..." # 選んだものに名前をつけて記録する
git push            # クラウドに上げる
```

**編集 → status → diff → add → commit → push。** これを繰り返すだけです。

### 差分の読み方だけ覚えてください

`git diff` の出力に出てくる記号は、この2つだけ分かれば読めます。

| 行の先頭 | 意味 |
|---|---|
| `+` | 増えた行 |
| `-` | 消えた行 |

**ここは飛ばさずに読んでください。** コマンドを打つのは AI ですが、
**何が変わったのかを確かめるのは自分の仕事**です。今日いちばん持ち帰ってほしいのがここです。

読みにくかったら、AI にこう頼めます。

```
いまの差分を、増えた行と減った行に分けて説明してください。
```

### GitHub の画面でも見る

```
いま上げたコミットを、ブラウザで見せてください。
```

`README.md` が書き換わっていて、**Commits** から**緑と赤の差分**が見えます。
ターミナルで見たものと同じです。**画面でもコマンドでも、読んでいるものは同じ**です。

---

## もう一度やる（時間があれば）

同じことをもう1回やると、履歴に2件並びます。「**積み上がっている**」のが目で見えます。

```
README.md に好きなものを1行足して、さっきと同じ手順で GitHub に上げてください。
最後に、これまでの記録を新しい順に並べて見せてください。
```

最後に打たれるのは `git log --oneline` です。

---

## こうなれば成功

- `git status` に `modified: README.md` が出た
- `git diff` に `+` と `-` の行が出て、**どこが変わったか自分で言える**
- `git commit` のあとに `1 file changed, ...` のような行が出た
- `git push` がエラーなく終わった
- GitHub の画面で、自分が書いた内容とコミットが見えている

---

## つまずいたら

| 症状 | どうするか |
|---|---|
| AI が status と diff を見せずに push まで済ませた | 「さっきの変更の差分をもう一度見せてください」と頼めば、`git show` で出してもらえます |
| `Please tell me who you are` と出て commit できない | 名前とメールが未設定です。[00-setup.md](00-setup.md) の「名前とメールを設定する」を AI に渡してください |
| コミットしたのに GitHub 上で自分のアイコンが付かない | メールの設定が GitHub のものと違っています。[00-setup.md](00-setup.md) を見てください。**記録自体はできているので、今日はそのまま進めて大丈夫です** |
| `git push` で `rejected` と出た | クラウド側が先に進んでいます。「`git pull` してから push し直してください」と頼んでください |
| `git push` で認証を聞かれた | `gh auth login` が終わっていません。[00-setup.md](00-setup.md) に戻ってください |
| 書き換えすぎて分からなくなった | 「まだ記録していない変更を、全部取り消してください」と頼めます（`git restore` が打たれます） |
| AI が勝手に 03 まで進んだ | 「先に進みすぎです。いま何をやったかだけ説明して、止まってください」と伝えてください |
