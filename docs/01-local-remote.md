# 01　手元とクラウド

コードが2か所にある、という話

---

## やること

このリポジトリを**自分のコピー**にして、そのコピーを**手元の PC に落とし**ます。

---

## 知っておくこと

コードは**2か所**にあります。

| どこ | 何があるか | 見え方 |
|---|---|---|
| **手元**（自分の PC） | 実際に編集するファイル | ターミナルとエディタに映っているもの |
| **クラウド**（GitHub） | 同じファイルと、これまでの記録 | ブラウザで見るもの |

この2か所を行き来する操作に、それぞれ名前がついています。

- **clone** … クラウドから手元へ、まるごと持ってくる（最初の1回だけ）
- **push** … 手元の記録をクラウドへ上げる
- **pull** … クラウドの記録を手元へ持ってくる

**ターミナルに映るのは手元だけ**です。クラウド側は見えないので、今どうなっているかは
ブラウザで確認するか、`pull` して持ってくることになります。

---

## 打つコマンド

### 自分のコピーを作る（ブラウザ）

1. このリポジトリのトップページを開きます
2. ファイル一覧の**すぐ上、右側**にある緑色の **Use this template** を押します
3. 出てきたメニューから **Create a new repository** を選びます
4. **Owner** が自分のユーザー名になっていることを確認します
5. **Repository name** に好きな名前を入れます（例: `github-intro-practice`）。半角英数字とハイフンだけにしてください
6. 公開範囲は **Public** を選びます（すでに選ばれていればそのまま）
7. 緑色の **Create repository from template** を押します

数秒待つと、**自分のアカウントの下に**同じ中身のリポジトリができます。
画面左上が `自分のユーザー名 / つけた名前` になっていれば成功です。

**ここから先は、この自分のコピーで作業します。** 元のリポジトリは変わらないので、
どれだけ壊しても他の人に影響しません。

### 手元に落とす（ターミナル）

分かる場所に移動してから `clone` します。デスクトップで構いません。

```bash
cd ~/Desktop
```

```bash
gh repo clone 自分のユーザー名/つけた名前
```

例えば `gh repo clone tokku5552/github-intro-practice` のように打ちます。

落ちてきたフォルダに入ります。

```bash
cd つけた名前
```

中身を確認します。

```bash
ls
```

---

## こうなれば成功

- GitHub の画面左上が `自分のユーザー名 / つけた名前` になっている
- `gh repo clone` が `Cloning into ...` と出て、エラーなく終わった
- `ls` に `README.md` `docs` `practice` が並んで見える

この状態で、**同じものが手元とクラウドの2か所にある**ことになります。

---

## つまずいたら

| 症状 | どうするか |
|---|---|
| **Use this template** が見当たらない | GitHub にログインしていない可能性があります。画面右上の **Sign in** からログインしてください |
| Owner に自分の名前が出ない | `Choose an owner` から自分のユーザー名を選んでください |
| `gh: command not found` | `gh` が入っていません。[00-setup.md](00-setup.md) に戻ってください |
| `gh repo clone` で `Could not resolve to a Repository` | ユーザー名かリポジトリ名が違います。GitHub の画面左上の表示をそのまま写してください |
| `cd` でフォルダに入れない | `ls` を打って、フォルダ名を確認してから入り直してください |
| `ls` に何も出ない | まだ `clone` したフォルダの外にいます。`cd つけた名前` で中に入ってください |
