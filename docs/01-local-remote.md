# 01　自分のリポジトリを作る

コードが2か所にある、という話

---

## やること

**自分の GitHub に、新しいリポジトリを作ります。** そしてそれを手元の PC に落とします。

このリポジトリのコピーではありません。**あなたのリポジトリを、ゼロから作ります。**

---

## 知っておくこと

コードは**2か所**にあります。

| どこ | 何があるか | 見え方 |
|---|---|---|
| **手元**（自分の PC） | 実際に編集するファイル | エディタに映っているもの |
| **クラウド**（GitHub） | 同じファイルと、これまでの記録 | ブラウザで見るもの |

この2か所を行き来する操作に、それぞれ名前がついています。

- **clone** … クラウドから手元へ、まるごと持ってくる（最初の1回だけ）
- **push** … 手元の記録をクラウドへ上げる
- **pull** … クラウドの記録を手元へ持ってくる

**画面に映るのは手元だけ**です。クラウド側は見えないので、今どうなっているかは
ブラウザで確認するか、`pull` して持ってくることになります。

---

## 貼るプロンプト

```
GitHub に新しいリポジトリを作って、手元に持ってきてください。

・名前は github-practice にしてください
・公開範囲は private にしてください
・README も一緒に作ってください
・作業しやすい場所に置いて、どこに置いたか教えてください
・終わったら、そのフォルダの中身を見せて止まってください
```

---

## AI が返すはずのもの

打たれるのは、だいたいこの2つです。

```bash
gh repo create github-practice --private --add-readme --clone
```

```bash
ls
```

**`gh repo create` が、クラウド側に空のリポジトリを作るコマンド**です。
`--clone` を付けているので、作ったあとそのまま手元にも落ちてきます。

**フォルダがどこに置かれたかは必ず確認してください。** このあとずっとそのフォルダで作業します。
分からなくなったら、いつでも AI に聞けます。

```
いまどのフォルダで作業していますか？
```

---

## こうなれば成功

- AI が「リポジトリを作った」と言い、`https://github.com/自分のユーザー名/github-practice` が出ている
- 手元にフォルダができていて、中に `README.md` がある
- **クラウド側と手元の両方に同じものがある**、と AI が説明している

ブラウザでも見ておきましょう。こう頼めば開きます。

```
いま作ったリポジトリを、ブラウザで開いてください。
```

---

## つまずいたら

| 症状 | どうするか |
|---|---|
| `Name already exists` と出た | 同じ名前のリポジトリがすでにあります。`github-practice2` など別の名前を頼んでください |
| `gh: command not found` | `gh` が入っていません。[00-setup.md](00-setup.md) に戻ってください |
| `gh auth status` で `not logged in` | ログインが終わっていません。[00-setup.md](00-setup.md) に戻ってください |
| AI が勝手に先まで進んだ | 問題ありません。「いま何をやったか説明して、止まってください」と伝えて、02 へ進んでください |
| フォルダがどこにあるか分からない | 「いまどのフォルダで作業していますか？」と聞いてください |
| リポジトリを作り直したい | **別の名前で作り直してください。** 消すほうは追加の権限が要るので、今日は消さずに置いておいて大丈夫です |
