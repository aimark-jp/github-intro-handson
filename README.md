## 進め方

各ページは同じ形で書いてあります。

- **やること** … そのページで何をするか（1行）
- **打つコマンド** … そのままコピーして貼れます
- **こうなれば成功** … うまくいったかの確認方法
- **つまずいたら** … よくある症状と対処

**置いていかれても大丈夫です。** 聞き逃しても、ページを読めば同じところに立てます。
分からなくなったら、いまいるページの「こうなれば成功」まで戻ってください。

質問はチャットにいつでも投げてください。
