## 進め方

各ページは同じ形で書いてあります。

- **やること** … そのページで何をするか（1行）
- **貼るプロンプト** … そのまま AI に貼れます
- **AI が返すはずのもの** … 実行されるコマンドと、確認しておきたいこと
- **こうなれば成功** … うまくいったかの確認方法
- **つまずいたら** … よくある症状と対処

**置いていかれても大丈夫です。** 聞き逃しても、ページを読めば同じところに立てます。
分からなくなったら、いまいるページの「こうなれば成功」まで戻ってください。

質問はチャットにいつでも投げてください。

## 触るファイル

| ファイル | 使うところ |
|---|---|
| 自分のリポジトリの `README.md` | 02 |
| `practice/members/<自分のユーザー名>.md` | 03・04・05 |

**`practice/members/` は1人1ファイル**です。自分の名前のファイルだけを作って、他の人のファイルは触らないでください。
そうしておけば、10人が同時に書いてもぶつかりません。

`docs/` 以下と `README.md` は手順書なので、触らずに残しておくと迷いません。
