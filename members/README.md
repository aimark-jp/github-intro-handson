# members — 自己紹介サイトに載せる

サイト: https://aimark-jp.github.io/github-intro-handson/

このフォルダに自分の自己紹介を追加すると、上記のページにカードとして自動で表示されます。
各カードには「ASK AI」ボタンがあり、押すと ChatGPT / Claude / Gemini がその人を紹介してくれます。

## ルール

1. **`members/<自分のGitHubユーザー名>/intro.md` を新しく作ってください。**
   フォルダを1人1つ作る形です。**このフォルダ名がそのまま、カードのユーザー名・アイコン取得元・GitHubリンクになります。** ここだけは自分の GitHub ユーザー名と正確に合わせてください。
2. 他の人のフォルダは触らないでください。1人1フォルダなので、全員が同時に作業してもぶつかりません。
3. 一覧に自分を登録するような別作業は不要です。フォルダを置いて PR がマージされれば、自動でページに反映されます（1〜3分ほどかかります）。

## `intro.md` のテンプレート

以下をコピーして、`members/<自分のユーザー名>/intro.md` として保存してください。

```markdown
---
name: あなたの名前
github: あなたのGitHubユーザー名
role: 一言で（省略可）
tags: [タグ1, タグ2]
---
ここに自己紹介を3〜5行くらいで自由に書いてください。
```

- `---` で囲まれた部分（フロントマター）は**全部省略可能**です。省略しても、本文だけでちゃんと表示されます。
- `name` を省略すると、フォルダ名がそのまま表示名になります。
- `github` は省略可能です（フォルダ名が使われます）。書く場合はフォルダ名と必ず同じにしてください。
- `tags` は `tags: [Git, AI]` のように書いても、`tags: Git、AI` のように書いても大丈夫です。

## 書ける記法 / 書けない記法

| 使えるもの | 書き方 |
|---|---|
| 段落 | 空行で区切る |
| 改行 | そのまま改行するだけ |
| 箇条書き | `- ` で始める行を続ける |
| 太字 | `**太字**` |
| リンク | `[表示テキスト](https://…)` |

**画像・表・コードブロック・HTMLタグは使えません。** そのまま文字として表示されます。

## アイコン画像（任意）

`members/<自分のユーザー名>/avatar.png`（jpg / jpeg / webp も可）を同じフォルダに置くと、それがアイコンとして使われます。
置かなければ、GitHub のプロフィール画像が自動で使われます。

- 目安: 200×200 程度、500KB 以下
- 2MB を超えるとチェックでエラーになります

## AI に丸ごとやってもらう場合

このリポジトリのフォルダを開いた状態で、自分の AI エージェントに次を貼ってください。

```
github-intro-handson のフォルダで、次をやってください。

・gh api user --jq .login で私の GitHub ユーザー名を調べる
・「add-」にその login を付けた名前でブランチを作る（例: add-yourname）
・members/<login>/intro.md を新しく作る
・中身は members/README.md のテンプレートに合わせる
  （frontmatter の name / github / role / tags を埋め、本文に自己紹介を3〜5行）
・github と <login> は必ず同じにする
・他のファイルは変更しない
・そのファイルだけを記録してブランチを GitHub に上げ、PR を作る
・PR の URL を教えて、そこで止まってください。マージはしないでください
```

## PR に赤いバツが出たら

Files changed タブに、どこが問題かが日本語で表示されます。直して push すれば自動で再チェックされます。
AI にはこう頼めます: 「PR のチェックが失敗しています。エラーを読んで直してください」

## 反映されるまで

マージ後、だいたい1〜3分でサイトに反映されます。タイミングが重なると数分待つこともあります。
